# Практическое задание №1
```jsx
initial={{ scale: 0 }}
animate={{ scale: 1 }}
transition={{ duration: 0.5 }}
```
# Практическое задание №2
```jsx
initial={{ x: -100% }}
animate={{ x: 0% }}
transition={{ duration: 0.5 }}
```
# Контрольные вопросы
1. Сообщить пользователю о его действиях и то что сайт/программа на них отреагировала
2. Для того чтобы сообщить о намерении анимировать
3. `duration` - длительность анимации, `delay` - задержка анимации
4. `spring` - эффект пружины
5. `opacity` и `transform` - это части браузера и не связаны с элементом напрямую, а `width` и `height` это свойства элемента
