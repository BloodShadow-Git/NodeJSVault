# Практическое задание №1
```jsx
<Card title="Кроссовки" price={5000} isAvailable={true} />
```
- Price - int\float\long\double (любой численный тип, как целочисленный, так и с плавающей точкой)
- isAvailable - bool
# Контрольные вопросы
1. "Атом" - минимальный элемент, а "молекула" - элемент составной (строка поиска = Label + Button в минимальной комплектации)[^1]
2. Можно просто указать сами данные, а язык сам разберётся
3. Никак нет, они доступны только на получение
4. UI - содержит "атомы" и "молекулы"
5. Деструктуризация позволяет разбить `prop` на составные части вместо того чтобы каждый раз распаковывать его

[^1]: Составной элемент может быть создан из элементов простых (как молекула состоит из атомов)
