# Практическое задание №1
```jsx
function MyCard() {
	return (
		<div class="card">
			<h2>Заголовок
			<img src="logo.png">
		</div>
		<p>Описание</p>
	)
}
```
Здесь имеется 3 ошибки:
1. Заголовок 2го уровня (h2) не закрыт
2. Изображение также не закрыто, либо как 2й тег (с открывающим и закрывающим тегами), либо как однострочный тег (формата `<img/>`)
3. Возвращение 2х элементов хотя допускается возвращение только одного
Исправленная версия:
```jsx
function MyCard() {
	return (
		<>
			<div class="card">
				<h2>Заголовок</h2>
				<img src="logo.png"/>
			</div>
			<p>Описание</p>
		</>
	)
}
```
Здесь:
- Закрыты все открытые теги, HTML это допускает, но не js
- Элементы `div` и `p` были объединены объектом пустышкой (`<>` `</>`)
# Контрольные вопросы
1. SPA парадигма предлагает использовать один файл для создания продукта, хотя как правило пишут один общий или группу файлов как базу, от которой наследуются
2. Для установки библиотек проекта используют команду `npm install` находясь в папке проекта
>Важно чтобы был файл `package.json` с списком библиотек и их версий
3. `Classname` в jsx используется вместо `class` так как в JavaScript `class` зарезервированное слово
4. `npm run dev` запускает скрипт из `package.json` с тегом `dev`, а по факту запускает сервер в режиме разработчика с горячей перезагрузкой
5. Все файлы исходного кода следует хранить в папке `src` (source - исходники), это считается хорошим тоном
