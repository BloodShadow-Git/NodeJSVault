# Контрольные вопросы
1. `<div>` - контейнер пустышка, а `<section>` - логический раздел контента (условно глава)
> Как правило браузер игнорирует `<div>` при анализе странице
2. `alt` текстовое описание картинки
3. `aria-label` - текстовое описание кнопки, для случаев когда картинки нет
4. Для динамического изменения `<head>` у страницы
5. `Focus trap` (англ: "Ловушка фокуса") - элемент показывающий к какому элементу применяется ввод с клавиатуры
